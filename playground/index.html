Tajweed Playground

Type or paste vocalised Arabic and see which tajweed rules apply, and exactly where. Everything runs in this page — nothing is sent anywhere. Click a marked stretch for the ruling behind it. No Quranic text is bundled here; the sample is ordinary Arabic composed for the purpose. The corpus covers seven topics and is silent outside them, so no match means no modelled rule matched.

Built from @tajweed/rules and @tajweed/core. Rules marked “awaiting reviewer sign-off” have been verified against the text but not signed off by a qualified reviewer.
